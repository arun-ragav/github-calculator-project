# 📖 About the Project

The **Scientific Calculator** is a web-based calculator that performs both basic arithmetic and scientific mathematical operations.

The application has a modern user interface and includes a personal identity section containing:

- Profile image
- Name
- Degree
- University
- GitHub profile

The calculator is designed to work on both desktop and mobile devices.

It also provides additional features such as:

- Scientific calculations
- Memory functions
- Calculation history
- Dark and light themes
- Copy result
- Keyboard support
- Local Storage

# ✨ Features

## 🔢 Basic Calculator

The calculator supports:

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal numbers
- Positive / Negative
- Delete
- All Clear
- Equal operation

---

## 🧪 Scientific Calculator

The calculator provides:

- Sin
- Cos
- Tan
- Log
- Natural Log
- Square Root
- Square
- Power
- Factorial
- Pi
- Euler's Number
- Reciprocal
- Parentheses
- EXP

---

## 💾 Memory Functions

The calculator supports memory operations:

| Button | Function |
|---|---|
| MC | Memory Clear |
| MR | Memory Recall |
| M+ | Memory Add |
| M− | Memory Subtract |

### Example

```text
50 → M+
AC → MR
