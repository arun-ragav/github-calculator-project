# 🧮 Advanced Calculator

A modern and responsive **Advanced Calculator Web Application** built using **HTML, CSS, and JavaScript**.

This project was created as a frontend development project to practice JavaScript calculations, DOM manipulation, local storage, keyboard events, responsive design, and GitHub deployment.

## ✨ Features

### 🔢 Basic Calculations

* Addition
* Subtraction
* Multiplication
* Division
* Decimal calculations
* Percentage
* Plus/Minus

### 🧮 Advanced Operations

* Square `x²`
* Square Root `√`
* Power `xʸ`
* Reciprocal `1/x`

### 📋 Additional Features

* Calculation history
* Clear calculation history
* Copy result
* Delete button
* All Clear button
* Dark mode
* Light mode
* Theme saved using Local Storage
* Calculation history saved using Local Storage

### ⌨️ Keyboard Support

The calculator supports keyboard input.

| Key         | Function       |
| ----------- | -------------- |
| `0 - 9`     | Numbers        |
| `+`         | Addition       |
| `-`         | Subtraction    |
| `*`         | Multiplication |
| `/`         | Division       |
| `Enter`     | Calculate      |
| `Backspace` | Delete         |
| `Escape`    | Clear          |
| `%`         | Percentage     |
| `.`         | Decimal        |
| `R`         | Square Root    |
| `S`         | Square         |
